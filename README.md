# CS216L_Project1_TaskManager

Task Manager Project Description Task Manager is a simple Java console-based application that helps users manage their daily tasks. Users can add, view, search, sort, and delete tasks. The application also allows users to restore the last deleted task using a stack.

Data Structures Used Singly Linked List: Used to store and manage tasks. Stack: Used to store deleted tasks and undo the last delete operation. Features Add a new task. View all tasks. Search a task by ID using Linear Search. Sort tasks by priority using Bubble Sort. Delete a task. Undo the last delete operation. View the stack. Exit the program. Input validation for menu choices and task priority.
